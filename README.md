Bem-vindo ao repositório do meu portfólio pessoal! Este projeto apresenta minha trajetória, habilidades técnicas, stack de tecnologias e formas de contato de maneira moderna, responsiva e interativa.

---

## ✨ Funcionalidades

- **🌐 Suporte Bilingue (i18n):** Alternância instantânea de idioma entre **Português (PT)** e **Inglês (EN)**.
- **🎨 Design Moderno & Responsivo:** Interface escura (*Dark Theme*) desenvolvida com Bootstrap 5 e CSS3 personalizado.
- **🌧️ Efeito Matrix Digital Rain:** Fundo animado interativo em Canvas com estilo Matrix nas seções Hero e Contatos.
- **📱 Totalmente Adaptável:** Layout fluido com navegação otimizada para dispositivos móveis, tablets e desktops.
- **📞 Acesso Rápido a Contatos:** Links diretos para WhatsApp e perfil do GitHub.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estrutura semântica do documento.
- **CSS3 / Bootstrap 5:** Estilização responsiva, componentes visuais e animações.
- **JavaScript (ES6+):** Lógica interativa, i18n e renderização do efeito Matrix via `<canvas>`.
- **Google Fonts:** Tipografia com as fontes *Poppins* e *Fira Code*.
- **Bootstrap Icons & Devicon:** Ícones para a stack tecnológica e contatos.

## 🚀 Como Executar o Projeto Localmente

Você não precisa de nenhum servidor backend ou bundler complexo para rodar este projeto.

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/VitorCreatorSWE/portfolio.git
   ```

2. **Acesse a pasta do projeto:**
   ```bash
   cd portfolio
   ```

3. **Abra o arquivo `index.html`:**
   - Basta dar dois cliques no arquivo `index.html` ou abri-lo diretamente em qualquer navegador moderno.
   - Alternativamente, se estiver utilizando o VS Code, pode usar a extensão **Live Server**.
